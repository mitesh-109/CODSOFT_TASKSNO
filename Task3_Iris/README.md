# Task 3 – Iris Flower Classification

The CodSoft brief asks for a machine-learning model that classifies Iris flowers into setosa, versicolor and virginica from sepal and petal measurements.

### Approach
- Load the Iris dataset.
- Inspect the class distribution.
- Split into training and testing sets.
- Standardize numeric features.
- Train Logistic Regression.
- Evaluate with accuracy, classification report and confusion matrix.
- Create a pairplot to visualize class separation.

The included `iris.csv` is generated from scikit-learn's standard Iris dataset and uses the same four measurements and three species.
