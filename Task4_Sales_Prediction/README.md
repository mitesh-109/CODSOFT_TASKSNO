# Task 4 – Sales Prediction Using Python

The CodSoft brief asks for sales forecasting using factors such as advertising expenditure and platform selection. This implementation uses the commonly used Advertising dataset with TV, radio and newspaper advertising spend as predictors and sales as the target.

### Approach
- Load the Advertising CSV.
- Inspect and clean the index column if present.
- Split data into training and testing sets.
- Train Linear Regression.
- Evaluate with MAE, RMSE and R².
- Plot actual versus predicted sales.

Dataset source: public `Advertising.csv` dataset from selva86/datasets.
