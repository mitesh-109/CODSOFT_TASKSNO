# CODSOFT Data Science Internship – Tasks

This repository contains three completed task implementations required for the Data Science internship: **Task 1 – Titanic Survival Prediction**, **Task 3 – Iris Flower Classification**, and **Task 4 – Sales Prediction Using Python**. The internship brief requires at least three tasks.

## Selected tasks
- Task 1: Titanic Survival Prediction – classification
- Task 3: Iris Flower Classification – classification
- Task 4: Sales Prediction Using Python – regression

## How to run
1. Install Python 3.10+ and the packages in `requirements.txt`.
2. Run each script from its task folder or open the scripts in Jupyter/VS Code.
3. Task 1 and Task 4 download their public CSV datasets automatically if the CSV is not already present.
4. Task 3 includes `iris.csv`, so it can run without downloading a dataset.

## Important
The task brief itself provides task descriptions but does not include the datasets. For transparency, the repository stores the public dataset URLs used by the scripts instead of claiming locally generated data is the original dataset.
